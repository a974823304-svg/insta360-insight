## 全局筛选器联动契约（2026-07-26 实装 + 浏览器验证）

左侧 `SideFilter` 的「应用筛选」是**真联动**（数据会变），不是只改 URL。

### 信号流（前端）
`SideFilter.onApply()` → `filter.apply()`（仅 `appliedRevision++` + 存快照）
→ 各数据页 `watch(() => filter.appliedRevision, () => store.loadAll())`
→ `store.loadAll()` 内部 `useFilterStore().toQuery()` 取出当前筛选
→ 随每个 API 请求的 `params` 发出 → 后端按筛选缩放/过滤/归一化 → 页面重渲染。

注意：`SideFilter` 不再直接调 `store.loadAll()`，只负责发信号；重拉由各自页面 watch 触发（解耦，避免重复请求）。

### ⚠️ 必守铁律：axios 数组参数不能用 `[]` 后缀
后端 `bindFilter` 用 `c.QueryArray("platforms")`（**裸 key**）收参。但 axios 默认会把数组序列化成
`platforms[]=抖音`（Rails 风格 `[]` 后缀），gin 的 `QueryArray` **读不到**，`f.Platforms` 变成空数组
→ 筛选**悄无声息地丢失**（后端按全量返回，UI 看起来「联动没反应」）。

已在 `frontend/src/api/request.js` 给 axios 实例加了自定义 `paramsSerializer`，把数组展开成
**同名 key 重复**（`platforms=抖音&platforms=B站`、`date_range=2024-04-20&date_range=2024-05-20`），
与后端完美匹配。**所有走 `request` 的 api 模块自动受益**；新增 api 模块务必复用 `request`，不要自建 axios。

验证证据（Edge 无头 CDP 实测）：选「抖音」→ 应用筛选后，达人数 `13,284 → 8,856`，
平台分布图刷新为 `抖音 100%`（renormalize 生效）。

### 后端确定性变换范围（mock 层）
- **缩放**：KPI 与趋势点按 `KpiScale = WeightedFactor × DateScale` 缩放并重新格式化。
  - `WeightedFactor`：平台权重 0.5、地区 0.3、赛道 0.2；单维选中占比，未选维度记 1.0；clamp[0.3,1.0]。
  - `DateScale`：时间跨度 /30 天（含首尾 +1 天），clamp[0.3,5.0]。
- **renormalize 仅限键名一致的三类分布**：`PlatformShare`(平台)、`TrackPerformance`(赛道)、`AgeShare`(年龄)。
  选中后把未选中项占比归零、选中项重算为占比之和=100%。
- **不 renormalize**：内容形式/话题/时长、市场竞品/地区/价格带、品牌情感/热词——它们复用同名类型但语义不同，
  强行 renormalize 会把图表清空。这些分布随 KPI/趋势一起缩放，但占比保持不变。
- **列表真过滤**：`insight/creator` 达人列表（平台+赛道，从 tags 判赛道）、`content` 列表（赛道）；
  `market/brand` 列表无匹配维度字段 → no-op 保持全量（已知限制，不改 JSON 契约）。
- **年龄档位值固定** `18-24 岁 / 25-34 岁 / 35-44 岁 / 45 岁以上`（与 `mock.AgeBands`、fallback options 一致），勿改 `18-24`。

### 新页面接入联动的清单
1. 页面 `script setup` 内 `const filter = useFilterStore(); const store = useXxxStore()`。
2. `onMounted(() => store.loadAll())` 首屏加载。
3. `watch(() => filter.appliedRevision, () => store.loadAll())` 监听应用信号重拉（记得 `import { watch }`）。
4. store 的 `loadAll()` 必须调用 `useFilterStore().toQuery()` 并把返回值作为 `params` 传入每个 api（本仓库 store 已统一如此实现）。
5. api 模块统一用 `request`（已修 `[]` 后缀问题），且**必须 `.then(r => r.data)` 拆信封**。
